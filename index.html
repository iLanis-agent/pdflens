PdfLens

Is this PDF broken, encrypted, or hiding something? PdfLens opens the file's skeleton - version, page count, every indirect object, document metadata, and encryption status - without a PDF viewer and without uploading anything.

Open PdfLens

What it reads

  • Header version, file size, %%EOF integrity (catches truncated downloads)
  • Full indirect-object map: number, generation, offset, /Type, /Subtype, stream presence
  • Page count from the page tree root /Count
  • Trailer: /Root, /Info, /Encrypt, /Size
  • Document info: title, author, subject, keywords, creator, producer (literal and hex strings, escapes, UTF-16BE)
  • Encryption detection - and honest labeling that encrypted strings stay ciphertext

Why trust it

The JavaScript engine is checked field-by-field against pypdf in tests/run_tests.js: 47 assertions over a five-file corpus - a 3-page document with metadata, a metadata-rich file, a 10-page document, an AES-256 encrypted document, and a truncated file that must produce a warning. Header/EOF facts are checked independently against the raw bytes.

Limits

Reads structure, not content: no page rendering, no text extraction, no decryption. Page count comes from the page-tree root /Count (correct for well-formed files). Object streams and xref streams (PDF 1.5+) are scanned by object pattern rather than decompressed, so heavily compressed modern files may show a partial object map - the engine says what it found, not more.
